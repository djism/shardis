Cost of the per-slot migration gate (ADR 033) on normal traffic, no migration running.
One Shardis node in cluster mode owning all 16384 slots, redis-benchmark -t set,get
-n 1000000 -c 50 -P 16 -r 100000, 3 rounds alternating the binary from before the
gate (iter-10 commit) and after. Apple M4, macOS under heavy swap (see SUMMARY.md).

            SET req/s (3 rounds)                 median     GET req/s (3 rounds)                 median
before      1,287,001  919,118  1,269,036        1.27M      1,315,790  1,358,696  1,432,665      1.36M
after       1,162,791  1,329,787  1,305,483      1.31M      1,282,051  1,400,560  1,390,821      1.39M

Difference: within run-to-run noise (rounds of the same binary differ by up to 30%).
An uncontended RWMutex RLock/RUnlock is two atomic adds; at ~1.3M req/s that's not measurable here.
